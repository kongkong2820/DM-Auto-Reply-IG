## 진행 사항

- [ ] /admin에 단순 DataTable 형태의 로그인 및 관리 화면을 구현한다.
- [ ] 공통 키워드 저장, 릴스 사용 여부·제목·날짜·ID·메시지·키워드·행별 저장을 제공한다.

- [ ] 로그인부터 릴스 및 공통 설정 저장까지 브라우저로 검증한다.
- [ ] 메시지를 비우고 저장하면 OFF가 표시되고 OFF 전환 시 입력값은 보존된다.
- [ ] caption과 메시지를 안전하게 렌더링하고 저장 결과가 재조회 후 유지된다.

## 기록 원칙

실제 구현·검증 후 결과 문서에 변경 파일과 검증 근거를 남긴다. 실제 API 응답이 필요한 항목은 추측으로 완료 처리하지 않는다. Secret과 사용자 원문 데이터는 기록하지 않는다.
