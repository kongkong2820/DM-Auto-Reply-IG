- 선행 작업: TASK-04, TASK-06

- 결과 문서: [RESULT-07](../results/RESULT-07.md)

## 진행 사항

- [ ] mediaId로 설정 조회 → enabled → 메시지 → 키워드 → 팔로우 확인 → 발송을 구현한다.
- [ ] 자기 계정 댓글 제외, HMAC 검증, ctx.waitUntil 처리와 ENABLE_AUTO_REPLY 전역 스위치를 유지한다.
- [ ] 키워드는 쉼표로만 분리하고 trim·빈 값 제거·소문자 정규화 후 contains로 매칭한다.
- [ ] 릴스 키워드가 NULL·빈 문자열·공백일 때만 D1 공통 키워드를 사용한다.

## 완료 조건 및 검증

- [ ] 설정 없음·mediaId 없음·OFF·빈 메시지·키워드 없음·불일치·D1 오류는 미발송이다.
- [ ] 팔로워 확인 성공에만 해당 릴스 메시지를 보낸다.
- [ ] 서로 다른 릴스의 메시지와 같은 사용자의 서로 다른 새 댓글을 검증한다.
- [ ] 사용자별 1회 제한이나 DEDUP_KV를 추가하지 않는다.

## 기록 원칙

실제 구현·검증 후 결과 문서에 변경 파일과 검증 근거를 남긴다. 실제 API 응답이 필요한 항목은 추측으로 완료 처리하지 않는다. Secret과 사용자 원문 데이터는 기록하지 않는다.
