# RESULT-07 — Webhook을 D1 기반 발송으로 전환

- 연결 작업: [TASK-07](../tasks/TASK-07.md)
- 상태: 진행 중
- 작성일: 2026-09-06

## 구현 결과

Webhook 로직을 `src/webhook.js`로 분리하고 D1 기반 흐름으로 전환했다. mediaId 설정 조회, enabled와 메시지 확인, 릴스별 키워드 또는 D1 공통 키워드, contains 매칭, 팔로우 확인, 릴스별 Private Reply 순서로 처리한다.

키워드는 쉼표만 구분자로 사용한다. 자기 계정 댓글, 설정 없음, 필수 ID 없음, OFF, 빈 메시지, 빈 키워드, 불일치, D1 오류 및 팔로우 미확인은 모두 미발송이다. 사용자별 발송 기록과 댓글 원문은 저장하지 않는다.

## 실제 환경 확인

실제 Webhook과 DM 호출은 실행하지 않았다. 기존 HMAC 검증, `ctx.waitUntil`, `ENABLE_AUTO_REPLY` 전역 스위치는 유지했다.

## 남은 문제와 후속 작업

팔로우 조회 실제 응답이 확인되기 전에는 정상 키워드 댓글도 미발송될 수 있다. 이는 Fail Closed 정책에 따른 동작이다.
