## 구현 결과

`/admin`에 프레임워크 없는 단일 관리자 화면을 구현했다. 로그인, 로그아웃, 공통 키워드 저장, 릴스별 ON/OFF·메시지·키워드 행별 저장, 20·50·100 선택, 숫자 페이지 이동, 로딩·빈 목록·오류 상태를 제공한다.

브라우저는 방문한 페이지별 cursor를 메모리에 보관해 화면에는 페이지 번호를 표시한다. API가 총 페이지 수를 제공하지 않으므로 확인한 페이지와 다음 이동 가능 여부만 보여준다. 서버 응답 데이터는 `textContent`와 form value로 렌더링한다.
